# FurniHouse Ethiopia 🏡

**Crafted with care. Designed for living.**

FurniHouse Ethiopia is a modern, customer-focused furniture shopping platform designed to showcase beautiful furniture inspired by Ethiopian craftsmanship. It provides customers with an elegant and convenient way to explore furniture collections, discover products, and request custom furniture designs.

🌐 **Live Demo:** https://furnihouse-ethiopia.vercel.app/

## ✨ Features

- **Modern Homepage:** Clean, elegant, and responsive landing page.
- **Product Collection:** Browse furniture with product images, descriptions, and prices.
- **Product Categories:** Explore Beds, Doors, Storage & Boxes, and Living Room furniture.
- **Shopping Cart:** Add furniture products to your cart.
- **Multilingual Interface:** Supports English, Amharic, and Afaan Oromoo.
- **Custom Furniture Requests:** Customers can submit requests for personalized furniture designs.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Elegant UI:** Modern layouts, animations, and consistent styling.
- **Ethiopian Currency:** Product prices displayed in Ethiopian Birr (ETB).

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Elizabethdebebe1234/furnihouse-ethiopia.git
```

### 2. Navigate to the Project

```bash
cd furnihouse-ethiopia
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit:

```text
http://localhost:3000
```
